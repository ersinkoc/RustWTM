# RustWTM 0.30.1 release scope and validation

## Scope

- AI assistant with the user's own API key: Anthropic (native Messages API),
  OpenAI, Gemini, OpenRouter, Groq, DeepSeek, Mistral, xAI and local
  OpenAI-compatible servers (Ollama, LM Studio). Explains one process or the
  whole PC from facts RustWTM gathers; the model may look up more through a
  bounded loop of read-only tools (six rounds, five minutes, cancellable).
  Available in the window (Settings → AI assistant, process menus, the system
  overview) and as `wtm ai`.
- Privacy and safety: off until the user agrees; keys sealed per Windows
  account with DPAPI; command-line secrets and the account name masked before
  sending; facts and tool results fenced as data; control tools never offered
  to the model; keys only over HTTPS or loopback, and redirects never followed
  with a key. Requests go from the user's session, never from the service.
- MCP server: tool code moved into the shared `wtm-ai` crate; new read-only
  tools (`process_report`, `process_tree`, `process_modules`, `services`,
  `startup_items`, `app_history`) and prompts.
- Process workspace: User name, Architecture, Elevated and File version columns;
  *Hide system processes*; collapsible tree nodes; grouping by user with
  *Sign out…*.
- The CPU overload alert closes itself 15 s after the load is back to normal
  unless held; suspending asks for confirmation.

IPC remains protocol 16.

## Verification

Provider adapters are tested against scripted fake transports: request shapes
(API version header, effort, refusal fallbacks, no sampling parameters), refusal
and truncation handling, error bodies, tool rounds that echo assistant turns
unchanged, the forced last round, invalid tool arguments, servers without tool
support and a non-retried key error. Redaction, DPAPI round trips, the WinHTTP
header and no-redirect path, and the CLI against a local fake OpenAI-compatible
server (model listing, a test request and an explain with one tool round) were
run on the developer host. No paid provider was called; a live check is
`wtm ai setup --provider anthropic`, `wtm ai key`, `wtm ai test`.

GUI tests render the AI settings page for every provider, the assistant window
when off and when a request fails, and the alert countdown with *Keep it open*.
The localized release review renders the new settings page in every captured
language. Hosted Windows CI adds 0.30.0 as a seventh pinned upgrade baseline.
