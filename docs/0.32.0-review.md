# RustWTM 0.32.0 release scope and validation

## Scope

Windows Task Manager parity for Performance, Processes and the system tabs,
with features from Process Explorer and System Informer. IPC moves to
protocol 17; the GUI and the service must be updated together.

- Performance: a page per physical disk, network adapter and GPU, each with
  the readings Task Manager lists. Internal SSDs add temperature and, for
  NVMe, wear; hard disks and USB drives are never asked, since asking could
  spin them up. GPUs add temperature, fan speed and memory clock. Devices can
  be hidden and reordered by a stable key (model and position, or the
  adapter's NET_LUID), so choices survive restarts. GPU engine graphs can be
  chosen; the CPU page lists each logical processor's speed; a summary view
  shows only the resources; a Battery page appears on PCs with a battery.
  Adapter pages and the combined Disk & I/O page list the busiest processes,
  labelled as covering all adapters or all devices, since Windows does not
  record which one a process used.
- Processes: most of Task Manager's Details columns (CPU time,
  Cycle, memory pools and deltas, page faults, I/O operations and bytes, GDI
  and USER objects, GPU engine and shared memory, Description, Publisher,
  Package name, UAC virtualization, DEP, Hardware-enforced Stack Protection,
  I/O priority) and an Efficiency mode column. Columns that need the process
  opened each sample are read only while shown; fixed facts are read once
  per process. Set affinity, Realtime priority (with a read-back) and Go to
  services. A read-only Threads view per process.
- System tabs: Startup impact from the account's last sign-in, read by the
  service for the connected account only (its SID comes from the pipe
  connection, never from the request; command lines are never read out),
  startup publishers, service groups, Send message, App history network
  bytes (two new history columns, added to older databases on open), a
  default start page and Always on top.

## Verification

`cargo fmt --check`, `cargo clippy --workspace --all-targets -D warnings`,
`cargo doc` with warnings denied and the 993 workspace tests pass on the
developer host. Failure paths are tested through seams and synthetic
fixtures; nothing exhausts host resources.

Checked on real hardware: GPU temperatures from two adapters, two NVMe
temperatures, MAC addresses, per-core speeds that vary by core, the startup
impact parser against the machine's own reports, and the cost of the new
per-process reads (security settings for 730 of 929 processes in 8 ms; I/O
priority, efficiency mode and package name in 5 ms). Thread start addresses
need full thread query rights; 87% of threads were readable.

The new pages, menus and the Threads panel were rendered in English and
Turkish at wide and compact sizes in both themes and inspected for clipped
or untranslated text. Hosted Windows CI adds 0.31.0 as an upgrade baseline.

Not provided, for want of a source: power usage per process and
per-process attribution of disk or network traffic to one device. Not
added in this release: Task Manager's Job object ID, Memory (active private
working set), Operating system context, Enterprise context and Extended
Control Flow Guard columns.
