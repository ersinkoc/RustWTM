# RustWTM 0.30.2 release scope and validation

## Scope

- Process list: hold Ctrl to freeze the list and the performance charts; list
  keys (Enter, Alt+E, Delete, Shift+Delete, Page Up/Down, Home/End,
  type-to-search and `/`); natural, accent- and case-insensitive name order
  through Windows' invariant-locale comparison.
- Service hosts name their services (refreshed every 15 s while Processes is
  open); Parent PID, Image path, Start time and Integrity columns; the
  integrity level in the details.
- Memory performance: in use, modified, standby and free pages (PDH "Memory"
  counters), paged and non-paged pool (GetPerformanceInfo) and hardware
  reservation (firmware-reported installed memory), read by the window
  without administrator rights.
- Network connections: Listening/Established/UDP filters, exact port or PID
  search, *No owning process* and *Exited* rows, double-click to Processes.
- Pins and notes on Services, Startup and Network rows, kept with the window's
  remembered settings.
- Windows integration: *Restart Windows Explorer*, standard-rights Run new task
  from an elevated window (through the desktop's Explorer), *Open Windows Task
  Manager once* past the IFEO redirect, and folder owners that work inside the
  folder.
- About: *What's new* from the built-in changelog and *Copy diagnostic
  information* without process, account, path or address data.
- Devices: SATA/ATA SMART readings for administrators, GPU driver version,
  date and Direct3D 12 feature level, per-core kernel time, hiding and
  ordering devices, and *Yield memory when hidden*.

IPC remains protocol 16.

## Verification

Workspace tests, clippy and rustfmt pass on the developer host. Real-system
proofs use harmless children only: a process started under a chosen parent
(this test process) and its exit code, a suspended child that is discarded, a
debugger-detached `cmd.exe` that runs to completion, a hidden command through
the desktop shell, the working directory read from this process and from a
`PING.EXE` child inside a temporary folder, and the memory breakdown and
integrity level of this PC. The Explorer restart order (polite close, end after
a timeout, a desktop Windows restores itself, no copy left suspended) is tested
through a seam; GUI tests use stubbed backend functions, so no test restarts
Explorer, opens Task Manager or ends a process.

Not run on real hardware: an actual Explorer restart, opening Task Manager
past an installed IFEO redirect, and Run new task from an elevated window.
SATA SMART remains unvalidated on physical SATA disks. Hosted Windows CI adds
0.30.1 as an eighth pinned upgrade baseline.
