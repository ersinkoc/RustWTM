# RustWTM 0.22.0 release review

Version 0.22.0 improves resource navigation, process inspection, compact
layouts and event delivery. It includes the reproduced fixes from
[Round 44](system-review-2026-10-29.md) and
[Round 45](system-review-round45-2026-10-29.md), with ten additional permanent
regression tests since 0.21.0. Dependencies, configuration formats and the IPC
protocol are unchanged.

## Changes

| Area | Result |
| --- | --- |
| Overview | Resource cards open the corresponding performance graph, support keyboard activation, expose current values to screen readers and display a focus outline. |
| Status toolbar | Actions wrap to the available width. Long messages and resource summaries remain readable without pushing essential buttons outside the window. |
| Process navigation | Keyboard and cross-page selections reveal their rows. Explicit Details requests clear stale filters, resume a paused list and expand the selected app group. Later manual scrolling is preserved. |
| Users | Both scroll axes keep long account names and large session lists usable in compact windows. Existing confirmation before destructive session actions remains intact. |
| Monitoring alerts | Old, repeated or failed CPU samples do not manufacture a sustained overload. A monitoring gap starts a new observation. |
| Governor | Toggling protection resets its observation timers so disabled time cannot cause immediate throttling. |
| Service events | An empty initial backlog no longer silences the first live notification. History is fetched once per connection, while reconnected backlogs stay silent. |

## Evidence

The linked reviews retain each finding's root cause, failed assertion, passing
control, narrow patch and permanent regression. The six finding verifiers each
passed three consecutive runs. New tests use synthetic snapshots/sessions,
supplied clocks, the offline GUI backend and small isolated test pipes with
fake notification callbacks. No exhaustion proof or real sign-out was used.

The last pre-versioning workspace run passed 632 tests with 16 ignored. The
release-version checks below are run again against 0.22.0 before publication.
Source UI verification covered light/dark themes, compact/wide windows,
keyboard interaction, five-language headless rendering and focused GPU images
in English, Turkish and German. The screenshots use fixture values, not the
developer's real processes or accounts.

## Validation boundaries

Machine-changing installer/SCM, firewall and IFEO checks are not enabled on the
developer's PC. The counted local test passes can include bodies that return
early while those environment gates are disabled. Hosted CI runs the actual
installation checks on disposable Windows machines. The 16 ignored tests are
existing timing, asset-generation, whole-drive and live-service checks; no test
was disabled or weakened for this release.

Physical fan writes, real CPU frequency changes, certificate-backed signing
and broader hardware-model certification remain outside these checks. The
hardware-provider self-test exercises fake control leases, bounds, expiry and
rollback; it does not certify firmware behavior. Published ZIP/MSI hashes and
read-only downloaded-binary smoke checks verify the distributed artifacts
without installing them locally.
