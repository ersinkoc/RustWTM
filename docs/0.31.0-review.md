# RustWTM 0.31.0 release scope and validation

## Scope

A visual redesign of the desktop window after the Windows 11 (Fluent) look.
No setting, default, policy or IPC message changes; IPC remains protocol 16.

- Geometry: controls have a 4-point and surfaces an 8-point radius; the square
  geometry rule is retired. Selected segmented choices are raised chips with a
  short accent underline; flyouts have soft shadows.
- Settings: every page (This window, Appearance, Process workspace, Charts and
  history, Service settings, Telegram, AI assistant) lists one option per row
  with a Windows icon, the title, an optional description and the control at
  the right edge. On/off options are switches with their state written beside
  them. Service policies use one column with a heading per policy.
- Charts draw no axes or tick labels: a tinted outline and grid, the top of
  the scale above the chart and the visible time span below it. Rate scales
  move in 1-2-5 steps.
- Performance: from 860 points of content width a rail lists the resources
  with their latest reading and a one-minute sparkline. The timeline toolbar
  is one row with icon buttons for sample, zoom and live actions.
- Processes: the resource cards form one continuous band; the process table
  has no outline and no row or column lines by default (both can be switched
  on); inspector tiles are rounded.
- Overview cards are rounded without the accent top line. The Limits and Kill
  list forms use the option rows. Plot grids are faint.

## Verification

`cargo fmt --check`, `cargo clippy --workspace --all-targets -D warnings`,
`cargo doc` with warnings denied and the workspace tests pass on the developer
host, as do the visual review renders (release, gauge, product expansion and
onboarding). The GUI suite has 331 tests; a new one checks that an option
row's title is level with its control. Existing tests that find controls by
name pass unchanged: switches carry the former checkbox labels, sliders and
fields are labelled by their row titles.

The release review was rendered in English, Turkish and German at 1440×1000
and 820×500 in both themes and inspected for clipped or overflowing text.
Hosted Windows CI adds 0.30.4 as an upgrade baseline.
