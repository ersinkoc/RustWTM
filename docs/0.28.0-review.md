# 0.28.0 release scope

This minor release adds desktop inventory and application management, searchable
navigation and a repository-transfer bridge. It retains the existing service,
IPC and MSI upgrade identities.

## Delivered behavior

- Hardware specifications: system/BIOS, CPU topology and reported cache/clock
  fields, board, RAM generation/form factor, disk firmware and GPU identity.
  Collection is read-only and bounded, with refresh and formatted copy.
- Installed desktop apps: bounded HKCU/HKLM registry discovery, searchable and
  sortable rows, scope filters, details and confirmed uninstaller handoff.
  Registrations are revalidated before launch. Launch does not imply removal.
- Ctrl+K: localized page search, descriptive results, keyboard/mouse selection,
  Escape and preservation of page filters/drafts and existing confirmations.
- Update bridge: desktop/CLI discovery and the installer query the verified
  repository ID, retain response-provided download/checksum URLs and preserve
  the discovered release page for manual recovery after a failed update.

## Explicit limits

Store packages, unregistered portable apps, package-manager updates, disk health,
battery and per-device history remain outside this release. Uninstall tests use
injected handoff seams; they do not remove software from the developer machine.
No new physical hardware writes are introduced.

The canonical destination is rustwtm/rustwtm and the website is rustwtm.com.
Repository transfer and website deployment are separate operations. The bridge
works with the original repository before transfer; a real transfer must retain
ID 1425760656 and release history. Previously installed clients still need the
original GitHub redirect to find their next update.

## Validation and release gates

Regression coverage includes changed/missing registrations, unsupported and quiet
uninstall commands, checksum rejection, latest/tag discovery before/after a
transfer, recovery links, static inventory freshness and GUI interactions.
CI runs the transfer-safe PowerShell discovery fixture without evaluating the
installer entry point or writing payloads.

The visual CI matrix includes both new inventory pages in all five languages,
both themes and wide/compact windows. The upgrade matrix retains 0.25.0 and
0.26.1 and adds the preceding 0.27.2 release with a pinned MSI digest. Installer
mutation tests run only in disposable hosted Windows runners.

Publication requires exact-source CI and release-workflow completion, ZIP/MSI
checksums and provenance, then downloaded version/CLI/provider checks. Local
development validation alone does not establish publication or a completed
GitHub transfer. Operational evidence is retained in the ignored release folder.
