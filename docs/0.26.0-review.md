# 0.26.0 release review

This minor release separates disk analysis from live file activity and remembers
administrator startup preferences. Signing preparation, build provenance and
installer/visual CI improvements are also included. No signing account has been
configured, so public-trust Windows signatures are not part of this release.

## Disk analysis

Analysis opens in a dedicated page. Live file activity cannot push its rows out
of view; the three result lists use the available viewport height. Back/Open
retains the result, expanded folders and scroll position. Folder columns adapt
to compact windows. Reopening a pending scan reuses its worker instead of
accumulating scans blocked in filesystem access.

The displacement regression failed before the change: adding 20 live file
entries moved the first analysis row from y549.5 to y1022.5. Permanent tests now
cover that trigger, all three lists scrolling to their final row, and full-app
compact navigation retaining the scroll position. The GUI suite passed 180
tests with 2 existing ignored. Eighty analysis/activity screenshots rendered
successfully across five languages, two themes and two window sizes.

## Administrator startup

An elevated GUI launch remembers the administrator preference. Protected
installations use fixed per-user interactive-token tasks for manual launch and
optional sign-in startup. Task owners are administrators/SYSTEM; the ordinary
user receives only read/execute access. No password is stored and no arbitrary
executable or task arguments are accepted. Portable builds retain the ordinary
UAC fallback. Settings expose both preferences and save errors. A scheduled
copy without elevation falls back directly to UAC rather than relaunching the
same task repeatedly. Uninstall removes owned task definitions.

Windows canonicalizes task principals to account names. Both validation and
cleanup resolve those names back to SIDs before comparing ownership. The
read-only PowerShell regression covers account-name/SID equivalence.

## Validation boundary

The feature commit e30bd27e4db0299c093e1500a68c32b4ff13e179 passed all seven CI
jobs in run 41837117921, including 666 source tests (0 failed, 17 ignored),
coverage, fresh MSI/script installation, real task registration/ACL checks,
repair, downgrade rejection, configuration/history retention, uninstall task
cleanup, localized GPU rendering and installer provenance verification.

Release preparation reruns checks for the versioned source and upgrades from
the published 0.25.0 MSI with its pinned SHA-256. The tag must identify that
exact green source; the release workflow separately rebuilds and attests the
final ZIP/MSI. Downloaded assets require checksum, version, read-only binary
smoke, MSI metadata and attestation verification before publication is reported
as verified.

The known developer-machine TCP lookup test failures are reported separately
from hosted Windows results. Tests are not weakened to accommodate them.
No real installation, scheduled-task registration, reboot/logon GUI test,
physical hardware writes or resource-exhaustion proof runs on the developer PC.
Hosted task definition/ACL checks do not constitute a manual Windows sign-in
and UAC experience test.
