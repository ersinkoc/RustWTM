# 0.24.1 release review

## Scope

This publishes the Docker monitoring and design changes reviewed in
[0.24.0-review.md](0.24.0-review.md), with one native timeout correction. The
0.24.0 source tag remains unchanged. Its release job failed before publication;
there are no 0.24.0 downloadable assets.

## Reproduced failure and correction

Hosted release run 41680831660 reproduced a silent named-pipe request returning
`ErrorKind::Other` instead of `TimedOut`. `GetOverlappedResultEx` accepts whole
milliseconds; truncating the remaining duration can expire a wait before the
high-resolution deadline. Checking the clock alone misclassified that result.

Native `WAIT_TIMEOUT` and `ERROR_IO_INCOMPLETE` (a pending zero-millisecond poll)
now classify as `TimedOut`, independently of the clock. Other failures retain
their existing classification. Cancellation and draining are unchanged.

A deterministic regression injected both native error codes with a future
deadline and was observed failing before the fix. It also checks that an
unrelated native error is not a timeout before the deadline. All three pipe
HTTP tests then passed, including the bounded silent-peer cancellation test.
No resource exhaustion is used.

The API behavior is documented by Microsoft's
[GetOverlappedResultEx reference](https://learn.microsoft.com/en-us/windows/win32/api/ioapiset/nf-ioapiset-getoverlappedresultex).

## Validation boundary

Fresh local checks passed release identity, rustfmt, locked all-target Clippy
and workspace rustdoc with warnings denied. The locked workspace test run
returned 655 passed, 2 failed and 17 ignored. The two failures are the unchanged
`ports::tests::real_ports_can_be_read` and
`net::tests::finds_own_listening_socket` native TCP-state baseline. The opt-in
live Docker test passed again, including CPU/memory, detail identity and logs.
The optimized workspace build passed in 3m 26s. Hardware publish and simulated
self-test passed. The MSI built successfully; read-only inspection confirmed
ProductVersion 0.24.1, the Docker guide and both native provider DLLs. All four
executable versions and CLI/service read-only smoke checks passed. No local
installation was performed.

The Docker feature's visual and live-daemon evidence remains in the 0.24.0
review. This patch does not change its UI or sampling. Fresh source CI, coverage,
disposable-VM installation checks, release gates and downloaded-asset checks
are required for the 0.24.1 commit. Their exact results are reported in the
release hand-off. Local native TCP-state failures remain the existing baseline;
neither test is weakened or disabled. Developer-machine installation, fan writes
and host exhaustion are excluded.
