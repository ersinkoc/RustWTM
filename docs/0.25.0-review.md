# 0.25.0 release review

This release fixes the cropped resource gauges and refreshes chart presentation
across Overview, Performance and container details. The executable before/after
proof and visual review are recorded in
[visual-review-2026-11-04.md](visual-review-2026-11-04.md).

The gauge track now uses a centered path instead of an outside circle stroke.
Round caps, DPI-aware curve detail, scale marks and resource colors complement
the fully visible circle. Shared sparklines use fading fills and latest-point
markers, with room for their strokes at 0% and 100%. Performance plots have a
quieter grid and logical-processor tiles carry a subtle load tint.

The geometry regression covers 160 combinations. Before release preparation,
all 176 GUI tests passed (2 existing ignored), workspace Clippy and GUI rustdoc
passed with warnings denied, and GPU reviews passed for four DPI scales and
five languages in both themes and window sizes. The optimized GUI build passed.
The visual Rust source hashes are checked unchanged during version preparation.

Fresh 0.25.0 release identity, rustfmt, locked all-target/all-feature workspace
Clippy and private-item workspace rustdoc passed. The complete local workspace
run returned 656 passed, 2 failed and 17 ignored. The unchanged failures are
`ports::tests::real_ports_can_be_read` (no matching listener row) and
`net::tests::finds_own_listening_socket` (`Unknown(0)` rather than `Listen`),
matching the earlier local TCP-state boundary. The opt-in read-only Docker test
passed again against 55 containers, with CPU/memory samples, selected detail
identity and readable logs verified.

The optimized workspace build passed in 3m 20s. Hardware publish and simulated
lease/control self-tests passed. WiX built the MSI successfully. Read-only
inspection verified ProductVersion 0.25.0, the Docker guide and both native
provider DLLs. All four executable versions, CLI/service version smoke checks
and a three-row read-only CLI JSON sample passed. No local installation was
performed.

Final 0.25.0 workspace, build and installer results are recorded in the release
handoff. Hosted source checks, coverage, disposable-VM install/uninstall tests,
the exact tagged-commit release workflow and downloaded ZIP/MSI verification
are separate gates. The existing local native TCP-state test boundary is
reported independently of hosted Windows results; no test is weakened or
disabled to publish this release.

No registry dependency changes, service protocol changes, physical fan writes,
developer-machine installation or resource-exhaustion proofs are part of this
release. GPU fixtures contain synthetic workloads only.
